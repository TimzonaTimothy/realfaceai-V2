02Install

Up and running
in a minute.

Stuck? Email support@realfaceai.app and we’ll help.

  1. Open the installer

    Double-click the downloaded .dmg file.

  2. Drag to Applications

    Drag RealFaceAI into your Applications folder, then eject the disk image. Always launch it from Applications, not from inside the .dmg.

  3. Allow the first launch

    RealFaceAI isn’t notarized by Apple yet, so macOS blocks it the first time with a message like “can’t be opened” or “is damaged”. The app is fine — pick one of these, you only need to do it once:

    Option A — Right-click to open

    In Finder, open Applications, right-click (or Control-click) RealFaceAI → Open → click Open again in the dialog.

    macOS 15 Sequoia or later: if there’s no Open button, try to launch the app once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway, then confirm with your password.

    Option B — One command in Terminal

    Open Terminal (Applications → Utilities), paste this and press Return. It works the same in zsh (the macOS default) and bash:

    Terminal · zsh / bash
    $ xattr -dr com.apple.quarantine /Applications/RealFaceAI.app

    No output means it worked. If you see Permission denied, run it with sudo in front and enter your Mac password:

    Terminal · if permission denied
    $ sudo xattr -dr com.apple.quarantine /Applications/RealFaceAI.app
  4. Allow the camera

    Launch RealFaceAI and allow camera access when macOS asks. Missed it? Turn it on in System Settings → Privacy & Security → Camera.

  5. Sign in and go live

    Create an account or sign in, pick a face in the Studio and press Go live.

03OBS Studio

Use RealFaceAI
in OBS.

Send only the AI output into OBS as a Browser Source — no app UI, no virtual-camera setup. Works on macOS and Windows.

  1. Add a Browser Source

    In OBS, click + under Sources and choose Browser.

  2. Paste the popout URL

    In the Browser Source properties, set the URL to the one shown in RealFaceAI after you click OBS — it’s in the green badge on the AI Output panel. It looks like this:

    Browser Source URL
    http://127.0.0.1:8700/popout
    The port number may differ. Always copy the exact URL from the badge in the app.
  3. Match your stream resolution

    Set Width and Height to your stream resolution — typically 1920 × 1080. The page has a black background, so letterboxing is invisible.

  4. Start the stream, then click OBS

    Start the stream in RealFaceAI first, then click OBS in the app. The Browser Source shows “Waiting for stream…” until frames arrive; once the relay starts, OBS fills with the AI output only.
